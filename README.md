# Curr-culo-Pessoal-em-HTML-e-CSS
Um portfólio simples desenvolvido com HTML5 e CSS3, criado para apresentar minhas informações pessoais, habilidades, objetivos profissionais e contatos. Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web, com foco em boas práticas de estruturação, estilização e design responsivo.
